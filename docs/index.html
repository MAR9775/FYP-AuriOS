THE PIPELINE

From prompt to working environment.

01
You describe what you need
Type naturally or use your microphone. AuriOS understands English, Urdu, and Hinglish.
02
Intent is parsed locally
A rule-based parser with 160+ patterns handles common requests. Ollama (llama3.2) handles the rest. No data leaves your machine.
03
Six agents execute the pipeline
Detection → Download → Install → Configure → Validate → Environment. Each step streams live progress to your screen.
04
Your environment is ready
Software installed, PATH configured, virtual environment created. Installed apps launch automatically.

BEFORE YOU INSTALL

Prerequisites.

→
Windows 10 or 11 (64-bit)
AuriOS uses Windows-specific APIs: registry writes, UAC elevation, and silent EXE/MSI installer flags.
→
Ollama installed and running
Download from ollama.ai and run: ollama pull llama3.2
AuriOS will not start without Ollama on port 11434.
→
Administrator privileges
Required for system-level PATH configuration and silent software installation.
